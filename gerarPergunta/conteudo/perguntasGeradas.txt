2 - [MODIFICACAO] Adicione uma funcionalidade que permita o usuário escolher um intervalo personalizado (início e fim) e imprima todos os números primos nesse intervalo, em vez do intervalo fixo de 2 a 50.

Seu código:
----------------------------------------
for num in range(2, 51):
    primo = True

    for i in range(2, num):
        if num % i == 0:
            primo = False
            break

    if primo:
        print(num)
----------------------------------------

3 - [CORRECAO] O código calcula a soma de todos os elementos da matriz, mas pode apresentar um erro lógico se houver uma condição de borda não considerada. Qual é a possibilidade de erro que o aluno deveria verificar?

Seu código:
----------------------------------------
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

soma = 0

for linha in matriz:
    for elemento in linha:
        soma += elemento

print("Soma total:", soma)

4 - [PREVISAO] Se o usuário digitar a palavra "abacaxi", qual será a saída esperada do programa? Considere também o caso em que a entrada for uma palavra vazia.

Seu código:
----------------------------------------
texto = input("Digite uma palavra: ")
invertida = ""

for i in range(len(texto)-1, -1, -1):
    invertida += texto[i]

print("Invertida:", invertida)
