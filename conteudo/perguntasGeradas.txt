def calcular_media(notas):
    if len(notas) == 0:
        return 0
    soma = 0
    for nota in notas:
        soma += nota
    return soma / len(notas)


print(calcular_media([7.0, 8.5, 6.0, 10.0]))

2 - [MODIFICACAO] Modifique a função para que ela também retorne uma lista contendo os 
próprios números pares encontrados na lista de entrada, mantendo a contagem de pares.

Código-base:

def contar_pares(lista):
    quantidade = 0
    for i in range(1, len(lista)):
        if lista[i] % 2 == 0:
            quantidade += 1
    return quantidade


print(contar_pares([1, 2, 3, 4, 5, 6]))
print(contar_pares([1, 3, 5]))

def contar_pares(lista):
    quantidade = 0
    pares = []
    for i in range(1, len(lista)):
        if lista[i] % 2 == 0:
            quantidade += 1
            pares.append(lista[i])
    return quantidade, pares


def main():
    entrada = input()
    lista = [int(x) for x in entrada.split()]
    quantidade, pares = contar_pares(lista)
    print(quantidade)
    print(pares)


if __name__ == "__main__":
    main()

3 - [DESCRITIVA] Descreva, com suas próprias palavras, como o código funciona passo a passo
para encontrar o maior entre três números inteiros, sem usar a função max.

Código-base:
----------------------------------------
def maior_de_tres(a, b, c):
    if a > b and a > c:
        return a
    elif b > a and b > c:
        return b
    else:
        return c


print(maior_de_tres(3, 7, 5))
print(maior_de_tres(10, 2, 8))
----------------------------------------

resposta 3 -

Primeiro o código testa se o a é maior que o b e maior que o c, se for ele retorna o a. 
Se não for, ele testa se o b é maior que os outros dois e retorna o b.
Se nenhum dos dois for o maior, então o maior só pode ser o c e ele retorna o c.
Se tiver números iguais ele retorna qualquer um deles, porque tanto faz já que são o mesmo valor.

def fatorial(n):
    resultado = 1
    contador = 1
    while contador <= n:
        resultado = resultado * contador
        contador = contador + 1
    print(resultado)
