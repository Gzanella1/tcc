2 - [CORRECAO] O código imprime números primos entre 2 e 50, mas há um erro lógico: 
o número 2 não é detectado como primo. Por que isso acontece?

Seu código:
----------------------------------------
for num in range(2, 51):
    primo = True

    for i in range(2, num):
        if num % i == 0:
            primo = False
            break

    if primo:
        print(num)
----------------------------------------

resposta 2 - 
Na verdade, o código não possui erro em relação ao número 2.
Isso acontece porque, para num = 2, ou seja, um intervalo vazio.
Como o laço interno não executa nenhuma vez, a variável primo permanece como True, e o número 2 é corretamente identificado como primo.
Portanto, o número 2 é detectado corretamente como primo nesse código.imo

3 - [DESCRITIVA] Descreva, com suas próprias palavras, o que o código faz passo a passo, explicando cada parte do processo.

Seu código:
----------------------------------------
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

soma = 0

for linha in matriz:
    for elemento in linha:
        soma += elemento

print("Soma total:", soma)
----------------------------------------

resposta 3 - 

O código calcula a soma de todos os elementos de uma matriz 3x3.
Primeiro, é criada uma matriz com três listas internas, cada uma representando uma linha com três números.
Em seguida, a variável soma é inicializada com valor 0, que servirá para acumular os valores.
Depois, o programa percorre cada linha da matriz usando um laço for. Para cada linha, ele percorre todos os seus elementos com outro laço for.
A cada elemento visitado, seu valor é somado à variável soma.
Ao final da execução dos dois laços, todos os elementos da matriz terão sido somados, e o resultado total é exibido com um print.

5 - [MODIFICACAO] Adicione uma funcionalidade que verifique se o número é palíndromo considerando apenas os dígitos 
(ignorando sinais e zeros à esquerda), e exiba a versão invertida do número como saída adicional.

Seu código:
----------------------------------------
numero = input("Digite um número: ")

invertido = numero[::-1]

if numero == invertido:
    print("É palíndromo")
else:
    print("Não é palíndromo")
----------------------------------------

resposta 5 - 

numero = input("Digite um número: ")

# Remove sinais (+ ou -)
numero_limpo = numero.lstrip("+-")

# Remove zeros à esquerda
numero_limpo = numero_limpo.lstrip("0")

# Caso fique vazio (ex: "000")
if numero_limpo == "":
    numero_limpo = "0"

# Inverte o número
invertido = numero_limpo[::-1]

#print("Número invertido:", invertido)

# Verifica se é palíndromo
if numero_limpo == invertido:
    print("É palíndromo")
else:
    print("Não é palíndromo")
